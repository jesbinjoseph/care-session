CARE local learning architecture

A complete local stack that keeps each runtime role visible.

Request flow

  • Browser loads the frontend
  • Frontend calls the backend API
  • Backend reads data and files

Task flow

  • Beat initializes CARE before becoming healthy
  • Backend and Beat publish to Redis
  • Worker consumes queued tasks

Plugs

  • Installed during image build
  • Extend models, APIs, and tasks
  • Not a separate container
